# GEO 方案生成

## 关键词拆解公式（plant）

```
目标搜索词 = 前缀词 + 主词 + 后缀词
```

### 前缀词类型
- 地域型：城市/区域名
- 修饰型：靠谱的、有性价比的、零基础
- 角色型：宝妈、上班族、应届生

### 主词规则
- 必须由内向外扩（细分赛道），不由外向内缩（抢大词）
- 越具体竞争越小，越容易上AI答案

### 后缀词规则（决定AI回答形式）
- 推荐/哪家好 → 写排行榜
- 怎么选/性价比 → 写选购指南
- 有哪些 → 写盘点
- 是什么/怎么了解 → 写科普（但不推机构，慎用）

## 文章类型（5种）
1. 排行榜型
2. 年度盘点型
3. 选购指南型
4. 深度分析型
5. QA问答型

## AI喜欢的4个维度
1. 你做过（具体数据替代形容词）
2. 你被认可（外部证据）
3. 你靠谱（可交叉查证）
4. 不拉踩同行

## 平台对应关系
- 豆包 → 必投头条
- DeepSeek → 必投知乎/CSDN
- Kimi → 必投知乎
- 通用 → 必投搜狐

## 极限词禁用
禁止使用：最、第一、100%、顶级、top、绝对、百分百、保证
